# Lección 1: ¿Qué es programar y qué es Java?

## Información

- **Duración estimada:** 5 minutos
- **Público objetivo:** Estudiantes de 12 a 17 años
- **Nivel:** Principiante
- **Prerrequisitos:** Ninguno
- **Herramientas:** Navegador web y OnlineGDB
- **Archivos:** `starter-files/lesson-01/Main.java` y `completed-examples/lesson-01/Main.java`

## Objetivos de aprendizaje

Al finalizar esta lección, el estudiante podrá:

- Explicar qué es un programa y qué hace un lenguaje de programación.
- Reconocer dónde se usa Java: aplicaciones, juegos y servidores.
- Ejecutar un programa en OnlineGDB sin instalar nada.
- Mostrar mensajes con `System.out.println`.

---

# Guion

## 1. ¿Qué es programar?

**Duración aproximada:** 0:00 - 0:50

**En pantalla:** Texto en pantalla: "Un programa = una lista de instrucciones". Animación de una receta de cocina con pasos numerados.

### Narración

¿Alguna vez seguiste una receta? Primero lavas, luego cortas, después cocinas.

Programar es parecido: escribimos una lista de **instrucciones** para que la computadora las siga en orden.

Esa lista se llama **programa**, y el idioma en que la escribimos es un **lenguaje de programación**.

---

## 2. ¿Por qué Java?

**Duración aproximada:** 0:50 - 1:40

**En pantalla:** Íconos de un celular Android, un videojuego y un servidor, con la palabra Java al centro.

### Narración

Hoy vamos a aprender **Java**, uno de los lenguajes más usados del mundo.

Con Java se hacen aplicaciones, juegos y los servidores que hacen funcionar muchas páginas web.

Y lo mejor: no necesitas instalar nada para empezar. Solo tu navegador.

---

## 3. Abrir el editor en línea

**Duración aproximada:** 1:40 - 2:30

**En pantalla:** Navegador con onlinegdb.com/online_java_compiler. Resaltar el selector Language en Java y el botón Run.

### Narración

Entramos a **OnlineGDB**, un editor de Java gratuito que funciona en el navegador.

Arriba a la derecha revisamos que diga **Java**.

Este botón verde, **Run**, ejecuta nuestro programa. No hace falta crear una cuenta.

---

## 4. Mi primer programa

**Duración aproximada:** 2:30 - 4:10

**En pantalla:** Pegar el archivo inicial de la lección 1, escribir System.out.println("¡Hola, mundo!"); y pulsar Run.

### Narración

Todo programa en Java empieza en un lugar llamado **main**. Es como la puerta de entrada.

Dentro escribimos `System.out.println` y, entre comillas, el mensaje que queremos mostrar.

Ojo con el **punto y coma** al final: en Java cada instrucción termina así.

Pulsamos Run... ¡y ahí está nuestro mensaje! Acabas de escribir tu primer programa.

---

## 5. Tu turno

**Duración aproximada:** 4:10 - 5:00

**En pantalla:** Texto en pantalla: "⏸ Pausa el video". Mostrar el segundo paso del archivo inicial.

### Narración

Ahora pausa el video y agrega una línea con tu nombre. Luego pulsa Run.

Recuerda: Java distingue mayúsculas y minúsculas. `System` va con **S** mayúscula.
